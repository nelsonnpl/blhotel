# Product Direction

Build this project as high-performance corporate software: minimalist, data-dense, and productivity-oriented for professional users.

- Put productivity before decoration and clarity before novelty.
- Put structured information before empty space and hierarchy before cards.
- Maintain high density without disorder and keep interactions predictable.
- Treat tables as first-class work surfaces.
- Reuse existing components, tokens, APIs, and architecture.
- Preserve visual and behavioral consistency.
- Never invent data, metrics, states, or product copy.
- Do not add dependencies without demonstrated need.
- Treat performance as a product requirement.
- Make accessibility mandatory, including keyboard workflows and visible focus.
- Avoid AI-slop patterns: decorative cards, excess radii, glow, glassmorphism, arbitrary gradients, oversized headings, and marketing copy.
- Validate interface changes visually before considering them complete.

Use the project skills in `.agents/skills/` for detailed guidance:

- `enterprise-ui`
- `anti-ai-slop`
- `performance-first`
- `visual-qa`
