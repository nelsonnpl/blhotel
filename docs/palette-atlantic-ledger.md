# Paleta Atlantic Ledger

La interfaz es una superficie de trabajo de revenue, no una landing. La dirección elegida
combina azul pizarra profundo para sesiones largas, coral RIU como único acento de marca y
señales semánticas separadas para precio, riesgo y calidad.

## Tokens principales

La decisión sigue dos referencias de sistemas corporativos: los tokens semánticos deben
nombrarse por función y no por apariencia, y las visualizaciones deben usar un color de marca
por defecto, reservando colores adicionales para categorías o estados ([Atlassian Design Tokens](https://atlassian.design/foundations/tokens/design-tokens/),
[Atlassian Data Visualization](https://atlassian.design/foundations/color/data-visualization-color)).
Para los estados se conserva texto o símbolo junto al color; Carbon documenta que el color por
sí solo no es suficiente para comunicar severidad ([Carbon Status Indicators](https://preview.carbondesignsystem.com/building-blocks/core/patterns/status-indicators)).

Se retiró el lenguaje visual de neón, gradientes y transparencias del token base. Los cambios
son reversibles mediante el backup de la fase anterior.
